# Git Practice Project

**Author:** Md. Towfikur Rahman

## What this project does

This is a practice project for learning Git and GitHub. It contains a simple Python program that prints my name and today's date, plus calculator functions built using branches and merges.

## Project structure

- `src/main.py`: main program
- `src/utils.py`: calculator functions
- `docs/project-description.md`: project description

## How to run

    python src/main.py
